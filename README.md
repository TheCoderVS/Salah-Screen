# 🕌 Salah Screen

**Un écran moderne pour suivre les horaires de prière au quotidien.**

Salah Screen est une application web pensée pour afficher les horaires de prière de manière claire et élégante, notamment sur un écran de télévision.

## ✨ Fonctionnalités

- ⏳ Compte à rebours jusqu'à la prochaine prière
- 🕰️ Horloge en temps réel
- 🌙 Affichage des horaires de Fajr, Dhuhr, Asr, Maghrib et Isha
- ☀️ Affichage du lever du soleil
- 📍 Choix de la ville et du pays
- 🧭 Plusieurs méthodes de calcul des horaires
- 🕌 Possibilité de choisir le calcul de l'Asr selon l'école hanafite ou standard
- 📱 Interface adaptée aux ordinateurs, téléphones et écrans de télévision
- 💾 Mémorisation des réglages dans le navigateur
- 🎨 Design sombre et moderne avec des accents vert citron

## 🚀 Utilisation

1. Ouvre le site Salah Screen.
2. Clique sur l'icône ⚙️ pour ouvrir les réglages.
3. Choisis ta ville et ton pays.
4. Sélectionne la méthode de calcul et le réglage de l'Asr.
5. Clique sur **Appliquer** pour actualiser les horaires.

## 🌐 Technologies utilisées

- HTML5
- CSS3
- JavaScript
- [AlAdhan API](https://aladhan.com/prayer-times-api) pour récupérer les horaires de prière

## 📦 Installation

Aucune installation n'est nécessaire pour utiliser la version publiée du site.

Pour exécuter le projet localement :

1. Télécharge ou clone ce dépôt.
2. Ouvre le fichier `index.html` dans un navigateur.
3. Vérifie que ta connexion Internet fonctionne pour récupérer les horaires.

## 🚀 Publication avec GitHub Pages

Le projet peut être publié gratuitement avec GitHub Pages :

1. Ouvre **Settings** dans le dépôt GitHub.
2. Va dans **Pages**.
3. Dans **Build and deployment**, choisis **Deploy from a branch**.
4. Sélectionne la branche `main` et le dossier `/ (root)`.
5. Clique sur **Save**.

## ⚠️ À savoir

Les horaires dépendent de la ville, de la méthode de calcul et des paramètres choisis. Ils peuvent différer de ceux de ta mosquée locale. Pour les prières, mieux vaut vérifier les horaires recommandés par ta mosquée.

## 💚 À propos

Salah Screen a été conçu pour rendre le suivi des horaires de prière simple, lisible et agréable, avec une interface adaptée à un affichage permanent.
